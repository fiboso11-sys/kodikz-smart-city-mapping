# Phase 2.2 — Mobile UX

**Date:** 2026-07-16

---

## Copilot (`/survey-copilot`)
- Mobile-first `max-w-lg` shell
- Min touch targets ≥ 44–56px
- Large status type (4xl–5xl)
- Bottom padding for thumb reach
- Tabs: Home / Progress / Voice
- Full-screen blockage sheet on mobile

## Command Center (`/survey-guidance`)
- Responsive: stacked map + table on mobile; split on xl
- `map-shell` height clamps for phones
- Side panel scrolls independently

## Navigation
- Mobile drawer includes Survey Copilot + Command Center
- Desktop sidebar highlights live Phase 2 product routes

## Constraints
- No horizontal overflow on copilot cards
- Dark high-contrast theme for sunlight
- Arabic-ready: no absolute left/right-critical icon clusters in hero
