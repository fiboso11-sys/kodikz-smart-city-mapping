# Code of Conduct

## Our pledge

We pledge to make collaboration on this government pilot repository a respectful, professional, and harassment-free experience for everyone.

## Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Respecting differing viewpoints and experience
- Accepting constructive feedback
- Focusing on what is best for the pilot and the customer

Unacceptable behavior includes:

- Harassment, discrimination, or personal attacks
- Publishing others’ private information (including credentials) without permission
- Disruptive trolling or bad-faith engagement

## Responsibilities

Kodikz maintainers are responsible for clarifying standards and may remove comments, commits, issues, or PRs that violate this Code of Conduct.

## Scope

This Code applies within project spaces (issues, PRs, discussions) and when an individual is representing the project.

## Enforcement

Report incidents privately to the Kodikz Release Manager (see `SECURITY.md`). Dubai Infrastructure escalations follow the Pilot Support Plan.
