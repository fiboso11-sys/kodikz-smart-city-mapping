# Phase 2.1 — Data Model

**Date:** 2026-07-15

---

## SGE Snapshot (Per GPS Tick)

The primary record generated by the SGE on each GPS update:

| Field | Type | Description |
|-------|------|-------------|
| `vehicleId` | string | IMEI of the tracked vehicle |
| `assignmentId` | string | Route assignment ID |
| `routeId` | string | Assigned route ID |
| `segmentId` | string \| null | Current nearest segment |
| `timestamp` | number | Unix timestamp (ms) |
| `latitude` | number | WGS84 latitude |
| `longitude` | number | WGS84 longitude |
| `gpsAccuracy` | number | GPS accuracy in metres |
| `speed` | number | Speed in km/h |
| `heading` | number | Vehicle heading (degrees, 0-360) |
| `distanceFromRoute` | number | Perpendicular distance (metres) |
| `routeState` | RouteState | Current state machine state |
| `previousState` | RouteState | Previous state (for transition detection) |
| `headingStatus` | HeadingStatus | CORRECT / MONITOR / WRONG_DIRECTION |
| `completionPct` | number | Route completion percentage |
| `completionStatus` | CompletionStatus | Human-readable status |
| `completedLengthMetres` | number | Total completed distance |
| `remainingLengthMetres` | number | Remaining distance |
| `totalLengthMetres` | number | Total route length |
| `alertIssued` | boolean | Whether a voice event was triggered |
| `driverAction` | string \| null | Driver-reported action |

## Route Assignment

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Assignment unique ID |
| `vehicleId` | string | IMEI of assigned vehicle |
| `routeId` | string | Route to follow |
| `routeName` | string | Human-readable route name |
| `geometry` | LineString \| MultiLineString | Route polyline |
| `assignedAt` | number | Assignment timestamp |
| `status` | "active" \| "completed" \| "cancelled" | Current status |

---

## Route Segment

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Segment ID (e.g., "seg-0") |
| `index` | number | Sequential index |
| `startCoord` | [lng, lat] | Segment start point |
| `endCoord` | [lng, lat] | Segment end point |
| `lengthMetres` | number | Segment length |
| `bearing` | number | Segment bearing (degrees) |
| `completed` | boolean | Whether segment is done |
| `gpsSamples` | number | Number of valid GPS samples |

---

## Blockage Report

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique report ID |
| `vehicleId` | string | Reporting vehicle |
| `assignmentId` | string | Active assignment |
| `routeId` | string | Route where blockage occurs |
| `latitude` | number | Blockage location lat |
| `longitude` | number | Blockage location lng |
| `timestamp` | number | Report time |
| `reason` | BlockageReason | Category of blockage |
| `notes` | string (optional) | Free-text details |

### BlockageReason Enum

- `ROAD_CLOSED`
- `CONSTRUCTION`
- `POLICE`
- `ACCIDENT`
- `UNSAFE`
- `OTHER`

---

## Supervisor Vehicle Status

| Field | Type | Description |
|-------|------|-------------|
| `vehicleId` | string | Vehicle identifier |
| `driverName` | string | Driver name |
| `plateNumber` | string | Vehicle plate |
| `currentRoad` | string | Current road name |
| `routeState` | RouteState | Current guidance state |
| `deviationMetres` | number | Distance from route |
| `completionPct` | number | Survey completion % |
| `remainingDistanceMetres` | number | Distance remaining |
| `headingStatus` | HeadingStatus | Direction status |
| `gpsQuality` | GOOD \| FAIR \| POOR \| UNRELIABLE | Signal quality |
| `lastUpdateAt` | number | Last GPS timestamp |
| `wrongDirection` | boolean | Sustained wrong direction |

---

## GPS Quality Mapping

| Satellites / Accuracy | Quality |
|-----------------------|---------|
| Accuracy ≤ 10m | GOOD |
| Accuracy 10–25m | FAIR |
| Accuracy 25–40m | POOR |
| Accuracy > 40m | UNRELIABLE |

## Enums

### RouteState
```
NOT_STARTED | ON_ROUTE | WARNING | OFF_ROUTE | RETURNING | PAUSED | COMPLETED | GPS_UNRELIABLE
```

### CompletionStatus
```
NOT_STARTED | IN_PROGRESS | NEARLY_COMPLETE | COMPLETION_CANDIDATE | COMPLETED
```

### HeadingStatus
```
CORRECT | MONITOR | WRONG_DIRECTION
```

### VoiceEvent
```
LEAVING_ROUTE | WRONG_DIRECTION | RETURN_TO_ROUTE | BACK_ON_ROUTE | STREET_MISSED | SURVEY_COMPLETE | BLOCKAGE_RECORDED
```
